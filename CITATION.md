## DOI permanente

**Ainda não emitido.** Para versões a partir de 2026-11 (ou primeira release marcada no GitHub), um DOI permanente pode ser obtido via [Zenodo](https://zenodo.org) com a integração nativa GitHub → Zenodo. Passos:

1. Logar no Zenodo com a conta do GitHub.
2. Ativar o toggle do repositório `marcostorm/calor-verde-rb` no painel do Zenodo.
3. Criar uma release no GitHub (ex.: `v2026.11`) — o Zenodo automaticamente arquiva o snapshot e emite um DOI.
4. Atualizar este arquivo substituindo esta seção pelo DOI gerado (formato `10.5281/zenodo.XXXXXXX`).

Até lá, use a referência pela URL + data de acesso.
